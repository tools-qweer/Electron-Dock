# Windows 行为兼容合同

## 判定原则

“完全复刻”只指 Windows x64 上用户可观察的 Dock 行为，不包括 Qt 内部
对象模型、Qt 私有 API、Qt 二进制 `saveState()` 格式及其他操作系统的窗口
管理差异。

任何阻断项不能稳定复现时，本 Alpha 判定失败，不以“八九分像”升为稳定版。

## 阻断项

1. 面板从停靠区一次拖出主窗口，形成真实系统浮窗。
2. 拖出时指针在标题栏内的锚点不跳动，浮窗不抢走按住状态。
3. 面板 WebContents ID、页面内计数器和焦点状态在停靠/浮动迁移中不重建。
4. 已浮动面板可通过系统标题栏移动，并在一次拖动释放后重新停靠。
5. 支持左、右、上、下分割及中心标签合并；局部命中使用 Qt 的比例中心区
   和目标叶节点父分割方向，宽面板不得退化为固定像素边带判定；同一内部
   分隔线两侧及 splitter 本体必须归一为一个结构落位，不能随指针跨过分隔
   中心而切换成第二个空白位置。左右落位优先保持浮窗客户区宽度，上下落位
   优先保持浮窗客户区高度加停靠标题栏；局部和外沿目标必须共用该首选尺寸，
   预览与松手结果必须来自同一候选布局。仅当布局最小尺寸不允许时才可夹紧，
   连续往返不得累积放大或缩小。
6. 支持嵌套水平/垂直分割、活动标签和分割比例调整。
7. 浮窗移动过程中显示明确投放目标；无目标时保持浮动。
8. 主窗口和浮窗关闭、最小化、恢复及焦点关系不产生孤儿窗口。
9. 布局保存、重启恢复、非法状态回退和版本升级不丢失面板。
10. 多显示器、负坐标、显示器拔除及 100%/125%/150%/200% DPI 下坐标正确。
11. Escape 取消、拖动中窗口关闭、Renderer 重载等异常路径能回收状态。
12. 重复 100 次拖出/停靠后无 WebContents 增长、无窗口泄漏、无明显抖动。

## 非阻断扩展

- macOS 原生窗口行为。
- Linux X11。
- Linux Wayland（全局窗口坐标受平台限制，仅可作为实验性支持）。
- Qt 工具栏、菜单栏、状态栏和 MDI。

## 自动证据与人工证据

- 单元测试验证布局树不变量、状态迁移、恢复和坐标钳制。
- 真实 Electron smoke 验证同一个 WebContentsView 跨窗口重挂载，并贯通
  动态落位候选、预览和提交；局部/工作区外沿尺寸保持与原生最小尺寸夹紧
  已作为可重复断言。
- 指针手感、多屏 DPI、系统标题栏移动和视觉预览必须由人工验证；自动检查
  通过不等于这些项目已经验收。
